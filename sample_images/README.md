# Sample images

This folder is intentionally empty in the repository (`.gitignore` excludes images).

Only add photographs that you are **permitted** to use: pictures of yourself, or of
people who have given explicit consent. Never commit private photographs to GitHub.

Suggested test set (keep local):
- `me1.jpg`, `me2.jpg`: two photos of the same permitting person
- `other.jpg`: a photo of a different permitting person
- `noface.jpg`: any image without a face (landscape, object)
- `group.jpg`: a permitted photo with several faces
- `notanimage.jpg`: a text file renamed to `.jpg` (tests corrupted-file handling)
